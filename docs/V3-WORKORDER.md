# V3 work order (2026-10-13)

## 1. The author's requirement (overrides the Claude+Codex hard-wiring)
"It picks it up automatically, doesn't matter the LLM or the program, and it assigns a character to it, 2 max at a time, and starts the battle based on what's being used, and gives me the ability to stop animations too."

### Design (interfaces are binding; both workstreams rely on them)
- **Slots, not names.** Two fighter processes, slot `a` (left home) and slot `b` (right home): `minis.py run a|b`. `minis.py start` starts a **director** process (`minis.py director`) plus both slots. Slots with no assignment hide their window.
- **Sources** (`minis_core/sources.py`): a registry of detectors, each yielding `Activity(source_id, program, character, state, ctx_pct, plan_pct, plan_label, resets_in, last_active, events)`. Detectors:
  - `claude` (Claude Code transcripts, existing logic), `codex` (rollouts, existing logic), character = same name.
  - Process detectors (no file reading, stdlib/ctypes only): a table of known AI programs by executable name -> character, e.g. Cursor (`Cursor.exe` -> `cursor`), Gemini CLI (`gemini` cmdline) -> `gemini`, Ollama (`ollama.exe`, `ollama app.exe`) -> `ollama`, LM Studio (`LM Studio.exe`) -> `lmstudio`, Windsurf, Copilot/VS Code agent is too ambiguous: skip; aider/opencode by command line; anything else unknown never shows. State from CPU use of that process tree over the last few seconds (working above a threshold, idle otherwise); ctx/plan = None (plate shows `-`).
  - Never count a program twice (the Codex desktop app is `ChatGPT.exe` under `OpenAI.Codex_*`: it belongs to `codex`, not `chatgpt`).
- **Director** (`minis_core/director.py`, pure + testable): polls sources every 2 s, picks at most 2 by recency of activity, keeps assignments stable (a slot keeps its source until another source is active and the slot's source has been idle > 60 s), writes `%LOCALAPPDATA%\minis\assign.json` atomically: `{"a": {"source": id, "character": c, "program": name} | null, "b": ..., "ts": t}`.
- **Characters**: `assets/<character>/{sheet.png, sheet_l.png, proj.png, anim.json}`. Built from a roster `art/roster.py` (claude, codex, gemini, cursor, ollama, lmstudio, generic). Each `anim.json` gets `"character"`, `"display"`, `"tag"` (plate text, e.g. `/reverse`, `$reverse`, `gemini`), `"accent"` (hex), and `"signature": {"strike": <move>, "special": <move>, "super": <move>}`; every character has the full shared move set plus its three signature moves. The planner must read specials/supers from `signature`, never by character name.
- **Battle from usage**: bouts start from real activity, not only a timer: both sources working -> frequent spars ("clash"); one finishes -> handoff to the other; one at its limit -> KO + console; both idle -> occasional spar/ranged duel; one asleep -> no bouts.
- **Stop animations**: `%LOCALAPPDATA%\minis\control.json` `{"paused": bool}`; `minis.py pause` / `minis.py resume`; right-click menu item "Pause all animations" / "Resume". Paused = every fighter shows a static idle frame, no walking or bouts, plate still updates, minimal CPU.

## 2. Confirmed audit findings to fix (10 auditors, 2026-10-13)
**telemetry.py**: cached-parse path never re-applies 45 s waiting / 10 min idle / Codex plan-reset rules (cache parsed state + recompute age rules per poll); newest line > 256 KB yields nothing -> false `done` (keep previous snapshot / read further back); reset `prev`/`work_since` when the newest path changes; `os.listdir` year/month not guarded (crash); `getsize`/tail FileNotFoundError not caught; zero-token assistant lines lower ctx to 0 (skip); prune `_parsed` to current path; parse only appended bytes (offset) to cut CPU; stale-rescan every 5 s all night -> back off; tests must drive the real Tracker (not FakeTelemetry) with temp files and a fake clock.
**brain.py**: accept invites only before a deadline (in the plan); publish event changes immediately; ignore events older than ~3 s and carry a per-run id (restart replay/dedupe); stop walking on own limit; console only when partner is home; `cancel` event on drag / partner gone mid-bout, partner aborts; accept only when actually free; `hit_log`/`contact_log` bounded; use a monotonic clock for animation/timers (wall clock only for bus timestamps).
**minis.py**: per-iteration try/except with traceback to `%LOCALAPPDATA%\minis\<slot>.log` (rotating, small), never die silently; `running()` must verify the command line (stale pid after reboot); `stop` must match exact argv (`<python>, <ROOT>\minis.py, run, <slot>`) not substrings, use `%SystemRoot%\System32\taskkill.exe`/powershell full paths, report "could not verify" separately; selftest-gui: refuse unless taskbar edge is bottom and band <= 96 px, try/finally restoring prior state, do not keep raw captures that could contain taskbar button titles (save a thresholded diff mask, or crop to the empty zone only); scale change bug (`and False`) -> apply new scale/geometry; hide when taskbar not bottom or auto-hide; 'gone' payload with real ts and readers treat it as absent; menu blocks loop (keep heartbeat/topmost alive or handle via queued command); bus.write OSError caught; monotonic loop timers.
**shell.py**: handle WM_CAPTURECHANGED (end drag); `GetModuleHandleW.restype`; check CreateCompatibleDC/CreateDIBSection results.
**render.py / atlas.py**: blink key when ctx >= 90 regardless of state (cache + redraw sig); plate flips to the other side before clamping onto the sprite; fit long labels; bar segments from the rounded value; atlas validation (zero totals, loop_range); clamp bad frame index; projectile frame count from metadata, cached.
**art**: left-facing sigil redraw only where the flipped buffer is `cap`/`sigil` (it paints over hands/skin now); scarf length constraint (pole bug) + loop seams over `loop_range` + start from idle scarf; hand-polish frames: redraw sigil for left-facing; corner softening no-op; `zzz` glyph reads as "I"; `hit_reach` from real pixels.
**docs**: correct test counts, feed is read not written, handoff wording (finished fighter gives), bout trigger wording, HUD colour = ctx only, Codex dirs/labels/waiting rule, BRIEF zone, nonexistent "art README", document `run`, `--keep`, `MINIS_HAND_DIR`.

## 3. Rules (unchanged)
Read-only telemetry, numbers/enums only, no network, never open real transcripts in an LLM context (tests use synthetic fixtures), never touch Claude/Codex settings/hooks, write only under this folder and `%LOCALAPPDATA%\minis`, `stop` never kills a process it can't prove is its own, captures only taskbar rows of the empty zone.
