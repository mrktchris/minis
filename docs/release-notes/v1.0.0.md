**Your AI agents fight in your taskbar.**

Taskbar Fighters gives every AI coding tool on your computer a pixel-art fighter: Claude Code, Codex, Gemini, Cursor,
Ollama, LM Studio, Copilot CLI and more. Two fighters at a time stand in the empty stretch of the Windows 11 taskbar (on a
Mac, on top of the Dock), and what they do follows what your agents are really doing. They spar while both agents are
idle, clash while one is working, and hand over when a task finishes. When an agent hits its context limit, its fighter
gets knocked out.

## Download

| | |
| --- | --- |
| **Windows 10/11, no Python needed** | [**TaskbarFighters-windows.zip**](https://github.com/mrktchris/taskbar-fighters/releases/download/v1.0.0/TaskbarFighters-windows.zip). Unzip it and double-click `TaskbarFighters.exe`. Quit from the tray icon or with `TaskbarFighters-cli.exe stop`. |
| **pip (Python 3.12+)** | `pip install taskbar-fighters`, then `taskbar-fighters start`. On a Mac: `pip install "taskbar-fighters[mac]"`. |
| **From source** | `git clone https://github.com/mrktchris/taskbar-fighters && cd taskbar-fighters && pip install -r requirements.txt && python minis.py start` |
| **Let your agent do it** | Paste *"Install and run Taskbar Fighters from https://github.com/mrktchris/taskbar-fighters - follow AGENTS.md"* into Claude Code, Codex or Cursor. |
| **macOS (experimental)** | `pip install "taskbar-fighters[mac]"`, or `TaskbarFighters-macos.zip` (the source; run `scripts/setup_mac.sh`). Its test suite runs on macOS in CI; reports from more Macs are very welcome ([docs/MAC-TESTING.md](https://github.com/mrktchris/taskbar-fighters/blob/v1.0.0/docs/MAC-TESTING.md)). |

The Windows zip is not code-signed, so SmartScreen may ask once: click **More info, then Run anyway**. Run one copy at a
time: the zip, a pip install and a git checkout share one data folder.

## Highlights

- **Auto-detect.** Claude Code and Codex are read from their local session files (numbers only). About a dozen other
  tools are found in the process list. No hooks or config edits, and nothing is installed into your agents.
- **13 armed fighters in HD.** 128 px art by default (`size 96` or `size 64` for smaller). Each program gets its own
  fighter, and six extras can be worn by any program: Kunoichi, Knight, Barbarian, Monk, Nomad and Oni.
- **Every fighter fights like its weapon.** 8-10 weapon moves per character on top of the shared set: 3-hit strings, air
  juggles, throws, chain pulls, dash-through cuts, guard breaks, ripostes and weapon locks, with sparks per hit kind.
- **Cinematic set pieces.** Hand-directed exchanges for both fighters (a blade lock, a cross-cut freeze, an aerial finish
  and more) play at a match's dramatic moments.
- **Battles from real usage.** Best-of-3 matches with HP bars, supers, a signature ultimate per fighter, impact frames and
  a K.O. finisher.
- **Arena mode.** The fight breaks out onto a whole monitor: window edges become walls and ledges, glass cracks and
  shatters, beams clash. `arena --rounds 1|3|5|endless --intensity calm|normal|wild`. **Visual only - nothing real happens
  to your windows.**
- **Scoreboard, HUD plates, fighter select, tray icon** (menu-bar icon on a Mac), and a flash toggle for anyone who
  dislikes strobing.

## Privacy

It reads numbers and states only: no prompts, replies, window titles or file names. It makes no network calls and never
touches your agents or your windows. Details are in [SECURITY.md](https://github.com/mrktchris/taskbar-fighters/blob/v1.0.0/SECURITY.md).
