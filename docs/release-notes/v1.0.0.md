**Your AI agents fight in your taskbar.**

Taskbar Fighters gives every AI coding tool on your PC a pixel-art fighter: Claude Code, Codex, Gemini, Cursor, Ollama,
LM Studio, Copilot CLI and more. Two fighters at a time stand in the empty stretch of the Windows 11 taskbar, and what
they do follows what your agents are really doing. They spar while both agents are idle, clash while one is working,
and hand over when a task finishes. When an agent hits its context limit, its fighter gets knocked out.

## Download

| | |
| --- | --- |
| **Windows 10/11, no Python needed** | [**TaskbarFighters-windows.zip**](https://github.com/mrktchris/taskbar-fighters/releases/download/v1.0.0/TaskbarFighters-windows.zip). Unzip it and double-click `TaskbarFighters.exe`. Use `TaskbarFighters-cli.exe stop` to quit, or right-click the tray icon. |

| **From source** | `git clone https://github.com/mrktchris/taskbar-fighters && cd taskbar-fighters && pip install -r requirements.txt && python minis.py start` |
| **Let your agent do it** | Paste *"Install and run Taskbar Fighters from https://github.com/mrktchris/taskbar-fighters - follow AGENTS.md"* into Claude Code, Codex or Cursor. |
| **macOS (experimental)** | `TaskbarFighters-macos.zip`. The port has not been tested on real Mac hardware yet, so feedback is very welcome. |

The Windows zip is not code-signed, so SmartScreen may ask once: click **More info, then Run anyway**.

## Highlights

- **Auto-detect.** Claude Code and Codex are read from their local session files (numbers only). About a dozen other
  tools are found in the process list. No hooks or config edits, and nothing is installed into your agents.
- **13 armed fighters.** Each program gets its own detailed pixel-art fighter, and six extras can be worn by any
  program: Kunoichi, Knight, Barbarian, Monk, Nomad and Oni.
- **Battles from real usage.** Best-of-3 matches with HP bars, supers, a signature ultimate per fighter, cinematic
  finishers and K.O.s.
- **Scoreboard and HUD plates.** Each program shows its state, context fill and win-loss record, with Pause, Arena and
  Bout now buttons.
- **Fighter select.** A platform-fighter-style screen picks which program fights on each side and which character it wears.
- **Arena mode.** The fight breaks out onto a whole monitor: fighters jump between your windows and "shatter" them. It
  is visual only, and nothing happens to the real windows.
- **Tray icon, Start-menu shortcut, `restart`**, and a flash toggle for anyone who dislikes strobing.

## Privacy

It reads numbers and states only: no prompts, replies, window titles or file names. It makes no network calls and never
touches your agents or your windows. Details are in [SECURITY.md](https://github.com/mrktchris/taskbar-fighters/blob/v1.0.0/SECURITY.md).
