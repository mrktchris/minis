# Credits

All seven fighters, every frame, every effect and every projectile in `assets/` and `assets_hd/` are original art
generated by the rig in `art/`. Nothing below was copied into the sheets; the packs were studied frame by frame for
timing, keying, proportion and silhouette (see `docs/ANIMATION-NOTES.md`, section 3).

## Animation reference & inspiration

- **LuizMelo - Martial Hero** (https://luizmelo.itch.io/martial-hero), CC0. Studied: attack anticipation/smear
  structure, scarf secondary action, hit and death keys.
- **Mattz Art / xzany - Samurai 2D Pixel Art** (https://xzany.itch.io/samurai-2d-pixel-art), free tier (idle, run,
  attack 1, hurt). Studied: the hold-hold-hold-snap attack timing, sub-pixel idle, run lean. Licence: usable in any
  project, no redistribution as an asset, credit appreciated.
- **GandalfHardcore - FREE 2D Pixel Art Archer** (https://gandalfhardcore.itch.io/pixel-art-archer-character), free
  tier. Studied: the 11-frame draw-and-release as the model for charge -> release, 8-tone colour discipline, hit flash.
  Licence: commercial use and modification allowed, no redistribution, no AI training.

## Visual inspiration only (nothing downloaded, not asset sources)

- Game Academie store previews (https://game-academie.itch.io/).
- DullMesh - Rigged Stylized Cyber White Samurai (https://dullmesh.itch.io/free-rigged-stylized-cyber-white-samurai):
  the white-armour / neon-edge direction behind LM Studio's costume and the holographic afterimages.

The same credit line is written into every `anim.json` as `credits` so the engine can show it in-game.
